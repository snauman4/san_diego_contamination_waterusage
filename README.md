# San Diego Water: Use, Contamination & What You Can Do

An interactive, static web page that connects two things about San Diego County water:

1. **Water use**: residential gallons per person per day for 21 urban water districts (State Water Board data), with a district map, sector mix, monthly pattern, and a comparison to California's indoor-use standard.
2. **Contamination**: specific conductance (a proxy for dissolved salts and runoff) at ~1,600 creek, storm-drain, and lake stations (CEDEN and USGS), with a dot/heat map, year-by-year play, lakes and reservoirs, and a "near me" lookup.
3. **The connection**: a tap-to-ocean explainer and a chart that joins creek stations to district boundaries (point-in-polygon, run in the browser).
4. **What to do**: an action planner that totals water saved and the creek-protection pathways covered, plus calculators and a quiz.

Open `index.html` in a browser, or publish the folder with GitHub Pages. There is no build step and no server code.

## Files

| File | What it is |
|---|---|
| `index.html` | Page markup and styles |
| `app.js` | All interactivity (maps, charts, planner, quiz) |
| `sd-water-data.js` | Water-use data and district boundaries (generated by `scripts/build_usage_data.py`) |
| `sd-conductivity-data.js` | Per-station conductivity summaries and lake data |
| `vendor/` | Leaflet 1.9.4 and leaflet.heat (bundled, so the page has no CDN dependency) |

## Data sources

- Water use: [State Water Board, Urban Retail Water Supplier Conservation, Supply, and Demand](https://data.ca.gov/dataset/urws-conservation-supply-demand)
- District boundaries: [State Water Board System Area Boundary Layer](https://gispublic.waterboards.ca.gov/portalserver/rest/services/Drinking_Water/California_Drinking_Water_System_Area_Boundaries/FeatureServer) (2019 snapshot, still being verified)
- Conductivity: [CEDEN chemistry results on data.ca.gov](https://data.ca.gov/dataset/surface-water-chemistry-results), 2010-2026 except 2015-2016 (server timeouts), plus USGS Sweetwater and Loveland reservoir records (1998-2009) from the [Water Quality Portal](https://www.waterqualitydata.us/)

## Caveats

- Conductivity measures dissolved salts only. It does not measure bacteria, nutrients, or toxic chemicals.
- Station averages mix seasons and sampling programs. They are a guide, not a regulatory ranking.
- In this data, creek conductivity is *not* higher in the districts that use the most water per person (Spearman r about -0.4 across 17 districts). The page says so. Creek salinity depends on many other factors.
- The 47 gal/person/day indoor standard comes from California AB 1668 / SB 606 (effective 2025).
- The conductivity data-pull scripts are not included in this folder yet; `scripts/build_usage_data.py` is copied from the original project and expects its raw files.

## Publish with GitHub Pages

Settings -> Pages -> Deploy from a branch -> `main` / root. The site appears at `https://<user>.github.io/san_diego_contamination_waterusage/`.
